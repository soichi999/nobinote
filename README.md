# ノビノート（オンライン家庭教師 管理サイト / PWA）

チューター・生徒・保護者が同じ記録を見られる Web アプリです。ホーム画面に追加して
アプリのように使い、宿題・連絡・指導予定はプッシュ通知で届きます。

## 入口とパスコード

「学生・保護者です」／「チューターです」の2択 → パスコード入力（一度入力すればその端末では以後スキップ）。
学生・保護者は共通の入口ですが、チューターが生徒ごとに設定した**生徒用／保護者用の2種類のパスコード**の
どちらを入力したかによって、自動的に「生徒」「保護者」として区別されます。

- チューターの初期パスコードは **0000**（`config/tutor` に自動作成）。設定タブでいつでも変更可能。
- 生徒・保護者はパスコードで生徒本人が特定されるため、生徒を選ぶ操作は不要です。
- チューターが複数の生徒を担当している場合、最後に開いていた生徒が次回ログイン時にも自動で開きます。

> **セキュリティの前提**：パスコードの照合はブラウザ側で行っており、Firestore のルールでは
> 役割までは検証できません（＝URL と DB を直接叩ける相手には効きません）。URL とパスコードは
> 関係者だけに共有してください。

## 機能と役割ごとの権限

| 機能 | チューター | 生徒 | 保護者 |
|---|---|---|---|
| カレンダー・宿題タブ（宿題・指導記録・指導予定） | 宿題出題・指導記録/予定の登録可 | 宿題の進度更新のみ可 | 閲覧のみ |
| 模試（実力テスト） | 出題・採点 | 受験・提出 | 閲覧のみ |
| 成績 | 閲覧のみ | 登録可（順位・志望校判定も編集可） | 閲覧のみ |
| 月謝 | 登録・振込確認 | 非表示 | 閲覧のみ |
| 連絡 | 閲覧・返信可 | 閲覧・返信可 | 閲覧・返信可 |
| 設定：名前 | 編集可 | 編集可 | 閲覧のみ |
| 設定：誕生日・志望校・得意/苦手科目 | 閲覧のみ | 編集可 | 閲覧のみ |
| 設定：パスコード管理 | 可（生徒一覧・パスコード発行） | 非表示 | 非表示 |

### ホーム（カレンダータブ）の並び
- カレンダータブには「今日やること」「宿題の達成度」「今日の英単語・数学」を出さない（2026-11-23 ユーザーの指示）。
  カレンダーは模試の案内・カレンダー・登録ボタン・予定の一覧だけ。「今日やること」と達成度の部品は index.html の見えない入れ物に残してある
- 「今日の英単語」「今日の数学ⅠA」のカードは宿題タブの一番上（「毎日の学習」）に置く。英語・数学で同じ形：見出し「今日の英単語／数学ⅠA」の横に今日の分の横ゲージ（0/20・7/20・復習 あと3・完了）→ はじめるボタン → レベル1〜3のボタン（「レベル1」と定着％だけ）→ 定着の円グラフ。○日連続・この1週間（月〜日）は「くわしく見る」を開くと見える（開いたかどうかは描き直しても残る）
- 予定の一覧は「これからの予定」（近い順。今月を表示中は来月はじめ7日分も）＋「これまでの記録」（折りたたみ）
- 宿題カードはふだん期限・題名・完了だけ。添付・写真・質問・編集は「くわしく」
- 通知の案内は閉じられる（設定タブからもオンにできる）。ログアウトは設定タブ

### デザインの決まり（style.css の :root）
- 意味の色：--ok / --err / --warn と、それぞれ -soft（背景）・-line（枠）・-mid（グラフ・アニメ）。種類の色：--c-plan / --c-mock / --c-vocab / --c-math
- 角丸は --r-sm / --r-md / --r-lg / --r-pill の4つ。色帯は --accent-w（4px）
- 文字は .75rem 以上（カレンダーの予定バッジだけ例外）。ボタンなど押す所は高さ44px以上。絵文字は使わない（アイコンはSVGの線画）

### 学習を続ける・苦手をつかむしくみ
- **やっていない日の通知**：毎晩20時（日本時間）、今日の英単語・数学ⅠAがまだ終わっていない生徒にだけ通知。
  その教科の記録があるか、今日が期間の「毎日の英単語／数学」の宿題がある生徒が対象。
  Firebase が無料の Spark プランで Cloud Functions を使えないため、**GitHub Actions の定時実行**で送る
  （`.github/workflows/daily-reminder.yml` → `tools/notify/daily_reminder.mjs`）。
  - 必要な準備：Firebase コンソール →（歯車）プロジェクトの設定 → サービスアカウント →「新しい秘密鍵を生成」で JSON を作り、
    GitHub の Secret `FIREBASE_SERVICE_ACCOUNT` に中身を登録（`gh secret set FIREBASE_SERVICE_ACCOUNT --repo soichi999/nobinote < 鍵.json`）。鍵のファイルは登録後に消す。リポジトリには入れない
  - 試すとき：GitHub の Actions タブ →「夜20時の学習リマインド」→ Run workflow（dry_run が true なら送らずに対象だけ表示）
  - 注意：公開リポジトリの定時実行は、60日間リポジトリに更新がないと GitHub に止められる（Actions タブから再開できる）
  - `functions/index.js` の `dailyStudyReminder` は Blaze プランにしたとき用（同じ中身）
- **苦手まとめ**（成績タブの一番上。先生・保護者だけ）：英単語は出た単語数・1回目の正答率・レベル別の定着％・まちがえた回数が多い単語（上位15）。
  数学は `mathWeakHTML()`（数学の部分が作る：分野ごとの正答率・何回もまちがえた問題など）

### 宿題タブ（カレンダーと模試の間）
- 上に「まだの宿題／期限切れでまだ／できた宿題」の件数
- 並べ方を2つから選べる（端末に記憶）
  - **締め切り別**：「締め切り前」（期限の近い順）と「締め切り済み」（まだの宿題は新しい順）に分ける
  - **科目別**：教科（数学・英語…）ごとにまとめ、まだの宿題が多い教科を上に。上のボタンで1教科だけに絞れる。教科なしは最後
- どのまとまりでも、やっていない宿題を上に出し、できた宿題は「できた宿題 ○件を見る」にたたむ
- 宿題カードはカレンダーと同じもの（チェック・完了・写真・質問・編集がそのまま使える）。チューターは「宿題を出す」もここから
- タブのバッジ：やっていない宿題のうち期限切れか2日以内の件数（生徒・保護者）

### カレンダー（宿題・指導記録・指導予定を統合）
「宿題」と「指導記録」は1つの「カレンダー」タブにまとまっています。

- 上部に宿題の達成度（全体の円形グラフ）。**リングをタップすると、たまっている宿題を
  一覧表示**（宿題ごとの達成度も個別の円グラフで表示）
  - 達成度の集計対象は「**今週以降**で、かつ**次回の指導予定日まで**（次回予定が無ければ制限なし）」の
    締切の宿題のみ。先週以前の締切分は対象から除外される（一覧・カレンダー自体にはそのまま表示され続ける）
- カレンダーは○ではなく横長のバッジ（時刻や「指導日」「期限」など）で予定を表示。日付をタップすると
  その日の詳細（指導予定・宿題期限、チューターは月謝も）がポップアップで確認できる
- タブを開くと自動的に今日の日付までスクロールする
- カレンダーの下には、**選択している月の**宿題・指導予定・指導記録・予定を日付ごとにまとめたフィード
  （新しい日付が上）を表示。前後の月に移動すると自動的にその月の内容に切り替わる
- 日付詳細ポップアップに出てくる宿題は、タップすると進捗チェックまで含めた詳細に展開できる
- 指導記録の授業内容・所感は「詳細」ボタンでアニメーション付きに開閉（普段はタイトルだけの表示）
- チューターの登録（宿題を出す／指導予定／指導記録）と予定の追加は、カレンダー上部の2行のボタンから
  ポップアップを開いて入力する（生徒・保護者は「予定を追加」のみ表示）
- カレンダー上で同じ「予定」が連続した日にまたがる場合、隣り合う日付のバッジが角の丸みをなくして
  つながって表示される
- 宿題は3つの形式に対応（3つめ：毎日の英単語／数学ⅠA）
  - **単位ごとにチェック**：単位（問／ページ／回、または自由入力）と開始〜終了番号をチューターが設定し、
    生徒が1つずつチェック。達成度＝チェック済み数 ÷ 全体数（例：「6/10問」）
  - **完了・未完了**：達成度は0%または100%
  - **毎日の英単語／毎日の数学ⅠA**：期間（提出期限を選ぶと開始日はその6日前＝1週間が初期値）と「毎日の数」（英単語は語・数学は問。初期値20語／5問）を決める。
    期間中の各日、その数以上を直しまでやり切った日を1日分（足りない日は「20/30」のように表示）。全部の日にこなせば自動で達成100%。
    期間中は、その日の「今日の英単語／数学」の問題数がこの数になる（重なる宿題があれば多いほう。`hwQuotaToday`）。保存する項目は `startDate`・`quota`。記録は vocab.days / math.days の `done`・`total`
  - 教科は「なし」も選択可。写真は**複数枚**添付可能（提出のたびに追加できる）
  - チューターは宿題に**PDFを複数（合計750KBまで）添付**可能（教材やプリントの配布用、編集時は追加登録）。
    Firestoreの1ドキュメント1MB制限ぎりぎりのため、これ以上の大容量ファイルには対応できない
    （PDFが重い場合はWordの「図の圧縮」やMac Previewの「ファイルサイズ削減」で軽くしてから添付する）
- 指導記録（実施済み）と指導予定（Zoom URL・時刻つき）をチューターが登録
- **予定**：生徒・保護者・チューターの誰でも追加できる汎用の予定（タイトル・日付・時刻・メモ）。
  カレンダー・日付詳細・下部フィードすべてに反映される。カレンダー上のバッジには「予定」ではなく
  タイトルそのものを表示（収まらない分は省略）
- 宿題・指導記録・指導予定・予定はすべて登録後に**編集可能**（宿題/指導記録/指導予定はチューターが編集、
  予定は投稿した本人が編集）。連絡メッセージも自分の投稿を編集・送信取り消しできる
- 指導開始1時間前・宿題期限前日にプッシュ通知（要 Cloud Functions）。新しい宿題・指導記録・指導予定・
  予定・連絡が追加されるたびにも通知が届く

### 模試（実力テスト）
**形式は2つ**。出すときに選ぶ（ウェブ用データのあるテストはウェブが既定）。
- **ウェブ（マーク式）**：画面で問題を見てマークする。数学は共通テスト型（ア・イ…の枠に数字や符号をマーク）、
  選択肢は ⓪①… から選ぶ。マークは自動保存（端末にも控え）され、アプリを閉じても消えない。
  時間になるとその時点のマークで自動提出（閉じていたときは次に開いたときに提出）。提出するとすぐ自動採点し、
  結果・答案と正解・解答解説が見られる。問題データは `moshi/web/<id>.json`（正解なし）、
  正解はデータベースの `config/mockans-<id>`（提出後にだけ読み出す）。数式は KaTeX で表示
  受験画面は大問ごとに1つずつ表示し、右下のボタンで大問を切り替える（各大問のマーク数も表示）。
  英語など欄が1つの問題は「ア」を見せず、文中の空所は下線で表示。
  採点後は正答率の円グラフ（正解・部分点・不正解の問題数）を表示し、「弱点の問題に挑戦」で
  まちがえた問題と得点率60%未満の内容の問題を**1問ずつ**出題する。答え合わせをするとその問題の解説が出て、
  「次の問題へ」で進む。最後に結果と「まちがえた問題をもう一度」（模試の点数は変わらない。
  結果は `practice.<問題id>` に記録）。問題ごとの解説はデータベースの `config/mockexp-<id>`（提出後にだけ読む）
- **紙に記述（写真で提出）**：以下の流れ
先生が作った実力テスト（数学ⅠA 第1〜3部・英語）を生徒に受けさせ、分野ごとの弱点を確かめるタブ。
- チューターが「模試を出す」でテストと期限を選ぶ
- 受験前・受験中は、問題用紙・解答用紙のPDFをダウンロードできる（印刷して解く）
- 「解き始める」で制限時間のタイマーが始まる。残り時間は**開始時刻からの経過で毎回計算**するので、
  アプリが裏に回っても・閉じても止まらない。終了予定時刻も表示。時間切れになると画面を開いた時に知らせる。
  受験中は画面が自動で消えないようにする（Wake Lock に対応した端末のみ）
- **解答・解説PDFは提出後にだけ**ダウンロードできる（チューターはいつでも可）。PDFは公開フォルダには置かず、
  データベースの `config/mockkey-<テストid>`（分割数）と `config/mockkey-<テストid>-<番号>`（PDFをbase64で分割）に保存。
  ※ルール上は匿名ログインした誰でも読めるため、技術的に完全な鍵ではない（画面上は提出後まで出さない）
- 解き終わったら解答用紙の写真を撮って提出（写真は1枚ずつ `mocks/{id}/photos` に保存。1件1MBの上限を避けるため）
- チューターは提出写真を見ながら各問を ○／×／部分点 で採点（途中保存可。全問入れると「採点済み」）
- 採点済みになると、全員に合計点・分野別・難易度別の得点率と「復習したい内容」（得点率60%未満の内容）が表示される
- テストの一覧と各問の分野・内容・難易度・配点は `moshi/catalog.js`、PDFは `moshi/` にある。
  **正解・解説はこのリポジトリに入れない**（公開されるため）
- 期限はカレンダーにも「模試」として表示され、カレンダー下の日付別一覧にも模試のカード（状態・点数・「模試を開く」ボタン）が出る
- 生徒向けの使いやすさ：カードに「印刷→解く→写真で提出→結果」の手順を表示。受けていない模試があると
  画面上部に案内、受験中は残り時間のバーを上部に固定表示。写真は撮るたびに送信して一覧で確認・削除でき、
  「○枚で提出する」で提出する。採点後は解答・解説で見直す問題番号を表示
- チューターは出した模試を「編集」できる（テスト・期限・メモ）。受験が始まったあとはテストは変えられず、
  変えるときは「受験前の状態に戻す」（タイマー・提出写真・採点を消して受け直し）を選ぶ

### 今日の英単語（カレンダータブ）
- **レベル1・2・3**（カードのボタンで切りかえ。各レベルの定着％を表示。生徒も先生も変えられ、今日の分を始める前なら新しいレベルで作り直す）
  - レベル1：英検準2級（高1前半の基本重要語）250語
  - レベル2：英検2級の中心 317語（`moshi/vocab.js`）
  - レベル3：英検2級で差がつく難しめの語135語＋大問1に出る熟語100個
  - レベル1・3と、全レベルの空所補充データは `moshi/vocab_more.js`（`tools/build_vocab_levels.py` が `tools/vocab_src/*.json` から作る。手で直さない）。意味・例文はこのアプリ用に作成（市販の単語帳の内容は入れていない）
  - 新しい単語は選んだレベルから（使い切ったら次のレベル）、復習の時期が来た単語は全レベルから出す
- **英検の形式**：初めて出す単語は英検2級の大問1と同じ「（　）に入れるのに最も適切なものを4択」（選択肢は例文に合わせた形。まちがいの3つは文法的には入るが意味が合わない語）。
  2回目からは「下線部の語に最も意味が近いもの」と交互に出す。同じ日のまちがい直しでは空所補充を2回出さない（全く同じ問題にしない）
- 1日20問。英検の形式：例文が1つ出て、その中の単語1つに下線。下線の語に最も意味が近い英語を4択から選ぶ（類義語は `moshi/vocab_syn.js`。例文の中で置きかえられる語にしてある。ほかの3つは同じ品詞の別の単語・類義語から、意味が重なるものを除いて選ぶ）→ ○／✕を線で描くアニメーション → 「解答・解説」画面（あなたの答え・正解・問題文と訳・単語の意味・4つの選択肢の意味・覚え方）→ 次の問題
- 解説の画面に入ると「単語 → 意味 → 例文」を自動で読み上げる（答えをタップした瞬間に読み始める。iPhoneはタップと同時でないと再生できないため）。解説画面の「自動読み上げ」ボタンでオン・オフ（端末に記憶）。次の問題・閉じるで止まる
- 声は自然に聞こえるよう、あらかじめ作った音声ファイル（`moshi/audio/<単語>-<品詞>-w|m|s.mp3`、951個・約10MB）を再生する。英語（単語・例文）は Kokoro（am_michael）、日本語（意味）は VOICEVOX:冥鳴ひまり。「発音」「例文を聞く」ボタンも同じファイル。ファイルが読めないときだけ端末の読み上げに切り替える。単語や例文を変えたら `tools/make_vocab_audio.py` で作り直す（VOICEVOX を起動し、kokoro の入った Python で実行。変えた単語のファイルを消してから実行すると、そこだけ作る）
- 解説画面の下に音声のクレジット「VOICEVOX:冥鳴ひまり」を表示（VOICEVOX の利用規約による）
- 読み上げは端末の英語の声のうち自然なもの（Samantha など）を選び、効果音系・簡易音声の声は使わない
- 同じ単語をもう一度出すとき（まちがえた単語の復習・後日の出題）は、前回と同じ問題にしない：まちがいの3語をすべて別の語に入れかえ、正解の番号も変える（前回の選択肢は `words.<id>.prev` に記録）
- 20問終わってまちがえた単語があれば、全部正解するまでその単語だけを1問ずつ復習（まちがえた単語は列の最後に回る）。
  終わるまでその日は「完了」にならない。途中で閉じても続きから再開
- 出題：復習の時期が来た単語（最大12語）＋まだ出していない単語。1回目で正解するたびに次の出題を 1→2→4→7→15→30日後へのばし、
  まちがえたら翌日にもう一度出す
- 解説：意味・例文（その単語を黄色で強調）・訳・「覚え方・豆知識」（派生語・よく使う形・反対語・語源など）。
  「発音」「例文を聞く」ボタンで読み上げ（端末の音声）。絵文字は使わない
- カードに習得の円グラフ（全単語のうち 定着＝間をあけて3回つづけて正解・学習中・未出題 の3色、中央に定着％、出題済み％）と、連続日数・この1週間の実施日数・直近7日の実施を表示（保護者は見るだけ）
- 直しまでやり切った日は、カレンダーのその日のマスを薄い黄色にする

### 今日の数学ⅠA（カレンダータブ）
- 共通テスト形式の短い問題を1日5問（宿題「毎日の数学ⅠA」の期間中はその宿題の「毎日○問」。まだ解き始めていない日は開いたときにその数で作り直し、解き始めたらその日は変えない）。ア・イ…の枠ごとに数字か符号「−」をマークする（負の数は先頭の枠が「−」、分数は既約分数、根号の中はできるだけ小さく）
- 範囲は数学Ⅰ・A の7分野（数と式・2次関数・図形と計量・データの分析・場合の数と確率・図形の性質・整数）、84問（画面では「問」と表示。中身は数値を変えられる問題のひな形）。
- レベルは3つ：レベル1＝基本（教科書の公式をそのまま使う、29問）、レベル2＝標準（共通テストの小問、37問）、レベル3＝発展（共通テストの大問の後半・場合分けや組み合わせ、18問）。どの問題がどのレベルかは `moshi/math_daily.js` の `LEVEL1` と `add3`
- 問題の形は3つ：数字や符号をマークする問題、⓪①…から選ぶ問題（`F.ch(番号, 個数)`。マークの丸も ⓪〜 だけになる）、図つきの問題（`fig`：アプリが作る SVG。箱ひげ図・散布図・放物線のグラフ・三角形や円）。選択肢は文字でも図でもよい（`choices`。横長の図は1列、グラフは2列、短い文字は横に並べる）
- 会話・日常の形式（`talk`：太郎さん・花子さんの会話の吹き出し）：木の高さ・塔の測量・模擬店の売上・プレゼント交換（完全順列）・じゃんけん・曜日・記録のまちがい
- 同じ問題かどうかの目じるし `sig` は、問題文・答えの形・図・選択肢・会話をまとめた短い文字列（ハッシュ）
  問題・解説はこのアプリ用に自作（市販・過去問の文章は入れていない）。データは `moshi/math_daily.js`
- 各型は数値を seed（種）から作る。出題は「型 id ＋ seed」で記録し、同じ seed なら同じ問題になる。
  まちがえた問題をもう一度出すとき（その日の復習・後日の出題）は、前回と違う数値の問題にする（前回の問題は `items.<型id>.sig` に記録）
- 流れ：問題 → 枠をマーク（答えの形の枠に数字が入っていく。答えの形は画面上部に固定）→「答え合わせ」→ ○／✕のアニメーション →
  解答・解説の画面（まちがえた枠・正しい答え・あなたの答え・解き方（式の流れ）・ポイント）→ 次の問題
- 5問終わってまちがえた問題があれば、数値を変えた問題で全部正解するまで1問ずつ復習（まちがえたらまた数値を変えて列の最後へ）。
  終わるまでその日は「完了」にならない。途中で閉じても続きから再開
- 出題：復習の時期が来た問題（全レベルから最大3つ）＋選んだレベルのまだ出していない問題（分野が順にまわる）。そのレベルを出しつくしたら、そのレベルの定着していない問題 → 近いレベルのまだの問題で補う。1回目で正解するたびに次の出題を
  1→2→4→7→15→30日後へのばし、まちがえたら翌日にもう一度出す
- カードにレベルの切りかえ（レベル1・2・3とそれぞれの定着％。生徒が選ぶと記録され、まだ1問も解いていない日はその日の問題も作り直す。先生・保護者は表示だけ切りかわる）と、選んだレベルの習得率の円グラフ（定着＝間をあけて3回つづけて正解した問題の％、学習中・未出題の内訳、出題済みの％）、連続日数、この1週間の実施日数、苦手な分野（正答率80%未満で一番低い分野）を表示（保護者は見るだけ）
- やり切った日は、カレンダーのその日のマスの下に線を引く（英単語の黄色と同時に出せる。色だけでなく形でも分かるように）
- 記録は `students/{sid}/math/state`（items：問題ごとの記録、days：日ごとの結果、today：今日の進み具合（level つき）、level：選んだレベル）
- マーク欄は模試のウェブマーク式と同じ部品（`.mark-row` / `.bubble`、数式は KaTeX）。押す所は44px以上
- 時間をはかる：問題画面に経過時間と目安（レベル1＝1分30秒・レベル2＝2分30秒・レベル3＝4分）、解答画面に「かかった時間／目安」。画面を見ている間だけ数え、アプリを裏に回すと止まる。1回目の答えの時間を `items.<id>.tsum`（合計秒）・`tn`（回数）・`tlast`（前回）に記録
- 苦手まとめ（先生・保護者が成績タブで見る）：`mathWeakHTML()` が、分野ごとの正答率（1回目）と平均時間、何回もまちがえている問題（まちがい2回以上か、直近でまちがえたまま）、時間がかかっている問題（平均が目安の1.3倍より長い）を出す。記録がなければ空

### 先生用のお試し（記録されない・何度でも）
- 模試タブの「先生用：お試し受験」から、どのテストでも受験→自動採点→答案と正解→弱点の解き直しまで試せる。
  データベースには何も書かない（生徒の記録・成績に影響しない）
- 単語帳カードの「お試しで解く」から、毎回ランダムな10問で強制復習まで試せる。生徒の単語の記録には影響しない
- 数学カードの「お試しで解く」から、毎回ランダムな5問（数値も毎回変わる）で復習まで試せる。生徒の記録には影響しない
- 記録は `students/{sid}/vocab/state`（words：単語ごとの記録、days：日ごとの結果、today：今日の進み具合）

### 成績
- 外部の模試・テストごとに教科別の点数（素点／満点／偏差値）を何科目でも追加登録可能
- 模試ごとの合計点・順位（手入力）・志望校判定（設定タブで登録した志望校ごとにA〜E判定）を表示
- 科目別の得点率推移グラフ

### 月謝
- チューターが対象日（複数選択可）と金額を登録。「9/1 9/8 9/15　7,500円」のように表示
- 振込確認をトグルで管理。生徒には非表示、保護者は閲覧のみ
- 支払日の前日に、未確認（振込未確認）であれば**保護者だけ**にリマインド通知（要 Cloud Functions）
- **月謝の実績グラフ**（直近6ヶ月）：月ごとに振込確認済み（緑）／未確認（オレンジ）の内訳を積み上げバーで表示

### 連絡
- チューター・生徒・保護者共通のメッセージ欄。カレンダーのフィードと同じく**日付ごとにまとめて表示**
- メッセージへの**返信**（引用表示）、**写真の複数添付**に対応
- **既読状況は送信者のみに表示**（「既読：保護者」など）
- 自分が送信したメッセージは編集・「送信取り消し」（削除）が可能
- **スタンプ（簡易返信）**：👍🙏💪✅ の絵文字ボタンをワンタップで送信可能

### 設定（プロフィール）
- 名前：生徒・チューターが編集可、保護者は閲覧のみ
- 誕生日・志望校（最大10件）・得意/苦手科目（教科は数学/英語/国語/理科/理科基礎/情報/小論文/社会の
  大項目ごとに折りたたみ、チェックボックスで何個でも選択可）：生徒のみ編集可
- 変更を加えると保存ボタンが青く変わる（未変更時はグレーで無効ではないが操作不要なことが分かる表示）

教科は大項目ごとに色相を固定し、抽象度が上がるほど淡く表示することで、宿題・指導記録・成績すべてで
共通の色分けバッジとして扱われます。

メニューはアイコン付きのタブで、スマホの幅では画面の下に固定表示されます。
（以前あった「勉強時間」「参考書」タブは使われていなかったため外しました。記録済みのデータは消していません）

指導予定のZoom URLは端末に記憶され、次回の登録フォームにも自動入力されます（生徒ごとに固定のURLを
使っている場合、毎回入力しなくてよくなります）。

## 更新が反映されないとき

このアプリは PWA として `sw.js` でオフラインキャッシュを持っています。コードを更新して再公開したのに
画面が変わらない場合は、`sw.js` 内の `CACHE` の値（例：`"tnote-v2"`）を新しい文字列に変更してから
再公開してください。変更しないと、既にアプリを開いたことがある端末はキャッシュを使い続けてしまいます
（新しいバージョンが有効になった端末は、リロードのループを避けるため**タブごとに1回だけ**自動で
再読み込みされます）。

## セットアップ

### 1. Firebase プロジェクト
[Firebase コンソール](https://console.firebase.google.com/) でプロジェクトを作成し、
- **Authentication → Sign-in method → 匿名** を有効化
- **Firestore Database** を作成
- **Cloud Messaging → ウェブプッシュ証明書** で鍵ペアを生成（VAPID キー）

### 2. 設定値を貼る
「プロジェクトの設定 → マイアプリ → ウェブアプリ」の値を **2か所** に貼ります。
- `firebase-config.js`（アプリ本体。VAPID キーもここ）
- `firebase-config-sw.js`（Service Worker 用。同じ値）

### 3. Firestore ルールと公開
`firestore.rules` の内容を Firestore コンソールの「ルール」タブに貼って公開するか、CLIで:
```bash
npm install -g firebase-tools
firebase login
firebase deploy --only hosting,firestore
```
※ 通知には **HTTPS** が必須なので、Firebase Hosting や GitHub Pages などに公開して使ってください。

### 4. 通知（プッシュ）を有効にする
サーバー側から送るため Cloud Functions を使います（**Blaze プラン**が必要）。
```bash
cd functions && npm install && cd ..
firebase deploy --only functions,firestore:indexes
```
`functions/index.js` が、宿題・指導記録・指導予定・予定・連絡の追加を検知して、その生徒に紐づく端末
（書いた本人以外）へ通知を送ります。あわせて以下の定期リマインドを送ります。
- `homeworkReminder`：毎朝8時（日本時間）に、翌日が期限の未提出宿題をチェック
- `lessonReminder`：5分おきに、1時間以内に始まる指導予定をチェック
- `tuitionReminder`：毎朝9時（日本時間）に、翌日が支払日で未確認の月謝があれば保護者にだけ通知

いずれも複数の生徒をまたいで検索する（collectionGroup クエリ）ため、`firestore:indexes` の
デプロイ（複合インデックスの作成）が必要です。

### 5. ホーム画面に追加
- **iPhone/iPad**：Safari で開く → 共有 →「ホーム画面に追加」→
  ホーム画面のアイコンから起動 → 「通知をオンにする」
  （iOS はホーム画面に追加したアプリからでないと通知を許可できません）
- **Android/PC**：Chrome のインストールボタン →「通知をオンにする」

### 6. 初回の準備
チューターとして 0000 で入り、「設定」タブで生徒を追加し、生徒用・保護者用のパスコードを決めて
それぞれに伝えてください。あわせてチューターのパスコードも変更しておくと安全です。
